Project Title: Tic Tac Toe Game

Description:
This is a console-based C++ mini game developed to demonstrate basic programming concepts such as arrays, loops, functions, and conditional statements. The game allows two players to play Tic Tac Toe interactively with dynamic board updates, win/loss detection, and replay functionality.

Features:
-Dynamic game board display
-Two-player gameplay
-Input validation for moves
-Win detection using rows, columns, and diagonals
-Draw detection
-Replay option after game completion
-Simple console-based user interface

How to Run:
1. Compile: g++ main.cpp -o tictactoe
2. Run: tictactoe

Files:
-main.cpp → Source code of the game
-bank.dat → Sample move data for testing

Concepts Used:
-Arrays
-Loops
-Functions
-Conditional Statements
-Game Logic
-Input Validation
